# AUDIT-2026-08 — all-designs discrepancy pass (GS-6)

Scope: every design source in `docs/mockup/` against the shipped editor, after
the graph-scripting package (GS-1…GS-5b) landed. Sources: `DESIGN.md` ·
`DESIGN-nodegraph.md` · `DESIGN-panels.md` · `DESIGN-graphscripting.md` ·
`Crusty Node Graph.dc.html` · `Crusty Design System.dc.html` ·
`Crusty Graph Variables/Node Config Rows/Graph Debugging.dc.html` ·
`Crusty Plugin Manager.dc.html` · `Crusty Curve Editor.dc.html` ·
`theme.json` / `theme.rs`.

`AUDIT.md`'s deferred ledger, each spec's own *Punted* list and the ROADMAP
deferrals are **out of scope by construction** — they are planned absences,
not discrepancies.

## Method

1. **Claim enumeration.** Every concrete, checkable claim (token value, metric,
   state, copy string, gesture binding) was extracted per document. Four
   parallel read-only passes (one per document family) produced 68 candidate
   findings; the ~60 numeric token/preset values in `theme.json` were compared
   against `theme/tokens.rs` one at a time by hand.
2. **Verification.** Every candidate was re-checked against the code before it
   was believed — 9 of the 68 turned out to be misreadings of a spec line or of
   a rationale already recorded in the code, and are recorded as NO-FINDING.
   Visual claims were checked against screenshots of the running editor
   (`docs/mockup/gs6-shots/`).
3. **Classification.** DISCREPANCY (deviates from an undisputed claim) ·
   RULED (deviates, covered by a recorded ruling) · DESIGN-STALE (the mockup
   contradicts a newer decision — flagged, code unchanged) · JUDGEMENT (real
   gap, needs a design decision or non-trivial work) · NO-FINDING.

## 3. DESIGN-STALE — spec contradicts a newer decision (no code change)

1. **DESIGN-panels ▸ Editor Preferences ▸ Graph** still lists *Minimum distance
   (100px)* and *Below minimum, draw*, and a preview strip whose third sample
   "proves the fallback". The rows were removed by ruling; the preview ships
   three samples with a different third case. → amend the doc.
2. **Plugin Manager mockup ▸ footer** shows a plugins *folder path* and "N
   enabled". 39.8 shipped compile-time plugins (no plugin directory) with
   restart-only activation, so enabled ≠ loaded. The footer reports what it can
   honestly count: `N plugins · N loaded`.
3. **Plugin Manager mockup ▸ manifest facts** (Manifest / Entry / Engine) assume
   an on-disk manifest and entry DLL. The shipped facts are Module / Cargo
   feature / Kind / Origin.
4. **Plugin Manager mockup ▸ relaunch + engine-version-mismatch states** describe
   a hot-patchable, versioned plugin host; 39.8 explicitly did not port that
   model (its "deliberately NOT ported" list).
5. **DESIGN-nodegraph ▸ Pins** ("There is no Int, String…") predates 45-A's
   `PinType` growth. `tokens.rs` documents the appended ramp slots.
6. **Debugging mockup ▸ `F5` resume** predates the play transport's claim on F5.

## 4. JUDGEMENT calls — for the coordinator

Ordered by my estimate of value. None were changed.

**Cross-cutting**

1. **Motion tokens are not wired.** DESIGN.md specifies `duration_fast` 80ms /
   `duration_base` 140ms / `cubic-bezier(0,0,0.2,1)`, and `Motion::tokens()`
   carries exactly those values — but crusty-gui animates with exponential
   half-lives (`hover 0.012`, `state 0.06`) and never reads them. Recommendation:
   either drive crusty's animator from the tokens (a crusty-side change) or
   amend DESIGN.md to specify half-lives. Today the token file and the renderer
   disagree about what motion *is*.
2. **Typography has no `heading` (14px) slot.** 18/12/10.5/mono-12 all exist;
   nothing renders at 14. Either drop it from the spec or add the slot.
3. **Segmented control has no pressed or focused state** and no keyboard focus
   at all. The state ladder asks for both. It is now the most-reused control in
   the editor (prefs, plugin filters, graph toolbar, curve footer).
4. **Icon chrome tints live in `icon_classes.rs`, not `tokens.rs`** — the values
   match DESIGN.md exactly, but the accent entry hard-codes Steel's `#4FA3E8`,
   so an icon marked "accent" stays blue on Graphite/Tidepool/Rusty. Fixing it
   means passing the live palette into the icon service.
5. **Two icons (`Folder`, `Sun`) are `Authored`**, bypassing the white-source
   tint pipeline DESIGN.md ▸ Iconography describes.

**Panels**

6. Asset tile names are single-line with end-truncation; the doc asks for a
   two-line box breaking on `_`/`-`/case and ~60/40 **middle** truncation.
7. Per-type short display names ("≤12 mono chars, stored beside its assets-map
   entry") do not exist; tiles use the long `display_name()`.
8. Asset tooltip is four labelled lines, not the doc's name / `type · size` /
   mono path structure.
9. Utility-strip buttons are 22×18; the doc says 18px (ambiguous — square vs
   height). Left alone deliberately.
10. `Graph` and default-scene properties are raw text fields; the doc says every
    asset-typed property reuses the asset-reference field.
11. Picker actions are Copy/Paste/Clear; the doc lists New/Edit too.
12. Multi-slot material lists have no count/add/index affordances.
13. Settings footer has no "Restart now" action; `Reset All` does not confirm
    (the doc wants `Reset All…` + confirm dialog).
14. Tab options: Unpin / Split Right / Move to New Window / Focus Viewport ship
    disabled pending Task 58.5 — in place and dimmed, per the menu-shape rule.
    Viewport close is enabled where the doc wants it unavailable.

**Graph canvas**

15. Pin hover has no visual state (13px dot + 18% halo in the mockup) — only a
    tooltip.
16. A refused connection is silent; the spec wants both types named and a
    converter offered.
17. In-flight wire is solid `accent_active`, not dashed in the source colour.
18. No muted-wire state.
19. Break copy says "Delete N links" / "Cut N links"; the spec says "Broke N".
20. Backward-lane tie-break picks the side containing the target; the spec says
    the side nearer the source row. (Router tests pin current behaviour.)
21. Turn priority and the exec-wire override are stored and surfaced in prefs
    but not consumed by the router.
22. Group fit uses estimated 168×100 node bounds + 24px; spec says exact bounds
    + 12px.
23. Graph inspector (the four-block panel) does not exist.
24. Realm metadata: only the toolbar chip ships — no node subtitle, palette
    column/dimming or realm-change preflight.
25. Palette ranking is prefix/substring; spec wants prefix → whole-word → fuzzy
    with graph-context tiers.
26. Align appears at 2 selected nodes; spec says 3+. Aligning two nodes is
    legitimate — recommend amending the spec.

**Graph scripting**

27. Cross-group variable drops set the group but do not reorder.
28. Runtime kills use the circular `!` error badge, not the spec's `⊗`.
29. "+ Watch" in a pin tooltip is not an entry point (right-click only) — a
    deliberate GS-3 choice (tooltips do not own state).
30. **The config band drops at L3, not L2.** The spec's "L2 the band drops"
    conflicts with the shipped ladder, whose L2 keeps a value-only band (the
    flattened value outlives its row label). Recommend amending the spec — the
    band-with-values reads better than a bare slab at 35–60%.

**Plugin manager**

31. No "Clear filter" action in the no-match state.
32. The list does not scroll — rows past the viewport are dropped.
33. Load errors are wrapped text, not a bordered pre block with "Copy error".
34. No registered-content collision warning; no engine-version-mismatch state.
